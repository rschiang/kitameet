### Overpass API

<https://wiki.openstreetmap.org/wiki/Overpass_API>

查詢語法參考文件為 <https://dev.overpass-api.de/overpass-doc/en/>。主要端點為 <https://overpass-api.de/api/interpreter>，備用端點為 <https://overpass.kumi.systems/api/interpreter>，兩者查詢語法相同。擷取以 POST 方式查詢，必須帶 `User-Agent` 標頭，否則伺服器會回應 HTTP 406；伺服器忙碌時回應 429、502 或 504。查詢一律以 `out geom;` 輸出，多重多邊形關聯的成員幾何會一併取回。

### 臺北都會區大眾捷運系統兩側禁限建範圍公告圖查詢系統

<https://eng.dorts.gov.taipei/br>

臺北市捷運工程局依《大眾捷運法》公告的逐幅禁限建範圍圖，皆不需認證。圖幅索引由 ArcGIS FeatureServer 提供（<https://wwwgs.dorts.gov.taipei/server/rest/services/Hosted/BRshpNewCodeView/FeatureServer/0>，`outSR=3826`），逐幅 PDF 位於 `https://eng.dorts.gov.taipei/br/pdf/{圖幅名}.pdf`。

每幅為 AutoCAD 輸出的向量 PDF，內含 1/1000 地形圖底圖、捷運結構外緣、軌道中心線與限建線；圖面格網為 50 公尺 TWD67 TM2 方格網，圖幅索引則為 TWD97 TM2。本專案取站區五條路線共 35 幅：南港線、板橋線、淡水線、新店線與松山線（圖幅名 `SS`、線路代號 `G`）。新莊線的圖幅全部位於新生北路一帶，與站區無關，不採用。

### 國土測繪中心通用正射影像（WMTS）

<https://wmts.nlsc.gov.tw/wmts>

圖磚網址為 `https://wmts.nlsc.gov.tw/wmts/PHOTO2/default/GoogleMapsCompatible/{z}/{row}/{col}`，回應為 JPEG，須帶瀏覽器型 `User-Agent`。本專案以 2024 年版影像抽查延平南路、民生西路、館前路三處街廓，確認公告圖地形底圖的建物面與屋頂輪廓相符，且 OSM 漏繪的建物確實存在。

### EPSG:3826（TWD97 / TM2 zone 121）

<https://epsg.io/3826>

臺灣本島常用的平面坐標系統，中央經線 121 度、尺度 0.9999。本專案的局部公尺座標以此投影為基準。

研究小組《臺北車站方案 B′ 軌道配置構想》疊圖為方案 B 的正本，內容為 SVG 疊圖，正北朝上、y 軸向下，標示二島對齊的兩座新月台（長 410 公尺、16 節車廂）、四條新建股道、既有臺鐵與高鐵股道、機場捷運路線與捷運月台。該疊圖未公開發表，亦未納入版控。
